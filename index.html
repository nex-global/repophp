Native PHP Runtimes Repository

Kho lưu trữ APT chính thức cung cấp các phiên bản PHP độc lập, tích hợp sâu kiến trúc NexSAPI và tương thích tuyệt đối với phân vùng cô lập người dùng NexRealm.

Thiết lập nguồn APT (1-Click Setup)
curl -fsSL https://repophp.nexspace.dev/setup.sh | sudo bash

Cấu hình & Tích hợp NexRealm Sandbox

Sau khi cài đặt gói runtime, khởi tạo phân vùng cô lập người dùng và xuất cấu hình pool riêng biệt:

sudo nxr nexphp-config alice --php-version 8.4 --output-dir /etc/nexspace/nexphp/pool.d
